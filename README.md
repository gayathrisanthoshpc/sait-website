# SAIT Website Redesign (demo one)

A modern, responsive website redesign for the Students Association of Information Technology (SAIT), CUSAT.

## Features

- Modern responsive design
- About SAIT
- People & teams
- Events
- Placements & careers
- Alumni
- Achievements / Hall of Fame
- Student Activity Logger
- Announcements
- SAIT Archive
- My SAIT Journey

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```
Live URL : https://sait-website-ten.vercel.app/
